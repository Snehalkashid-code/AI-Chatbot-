# 🤖 AI Chatbot — Python

A beginner-friendly, rule-based AI Chatbot built with **pure Python**.  
No APIs, no external libraries — just clean Python logic!

---

## 💬 What can this Chatbot do?

| You say | Bot replies |
|---|---|
| `hi` / `hello` | Hello + time-based greeting |
| `what is your name` | I am AI Chatbot |
| `how are you` | Friendly response |
| `time` | Current system time ⏰ |
| `today` / `date` | Today's date 📅 |
| `what is the capital of India` | New Delhi 🇮🇳 |
| `who invented the telephone` | Alexander Graham Bell 📞 |
| `bye` | Good Bye! See you 👋 |

> ✅ 30+ General Knowledge questions supported!

---

## 🚀 How to Run

**Step 1 — Make sure Python is installed**
```
python --version
```

**Step 2 — Clone this repository**
```
git clone https://github.com/Snehalkashid-code/AI-Chatbot-.git
```

**Step 3 — Run the chatbot**
```
python chatbot.py
```
